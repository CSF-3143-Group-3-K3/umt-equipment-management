# UMT Campus Services

A small, browser-based prototype for UMT students, lecturers, and staff to request equipment and faculty rooms.

## Run it

Open `index.html` in a modern web browser. There are no packages or build steps.

## What is included

- Browse and search sample sports, event, computing, and photography equipment.
- Submit an equipment borrowing request.
- Request a faculty room for a date and time.
- Review recent requests and the full request list.
- Keep requests in the current browser using local storage.

This is a front-end demonstration. The sample inventory is fixed, requests are not sent to faculty staff, and local browser storage is not shared between users or devices.
